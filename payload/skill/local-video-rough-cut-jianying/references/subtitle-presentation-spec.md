### 6.5 动画禁止项

- 同一屏出现 2 种以上入场方式（例：上一条渐显、下一条向右滑动）。
- 单条片段同时叠加位移 + 缩放 + 模糊。
- 动画时长 > 片段时长的 0.4 倍（短于 1s 的字幕直接硬切）。
- 给长句（>12 字）加“擦除/滑动”，文字边播边读不现实。
- 情绪/祝福段落加动画。

## 8. 落地参数

| 操作位置 | 参数 |
|---|---|
| 文本 → 字体 / 字号 | 字语云黑宋 / 11 |
| 文本 → 样式 | 描边 8%、阴影距离 5、行间距 0.02 |
| 位置 | X=0，Y=-0.34（访谈类 -0.43） |
| 动画 → 入场 | 渐显，时长 0.25s（花字 0.3s） |
| 动画 → 出场 | 不添加 |
| 轨道 | 主字幕轨（14000）/ 花字轨（14010+） |
| 智能字幕识别后 | 一次批量设置「渐显 0.25s」，再逐条拆长句 |
